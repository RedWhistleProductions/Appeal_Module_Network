Network Module

Appeal docsModule standardBasicAdvancedGlobals

Script functions provided by the Network module. Prefix each call with Network; arguments below are consumed in the listed order. Plugin support and behavior may vary.

Basic covers ordinary application and game operations. Advanced covers explicit setup, backend management, and tuning. This classification describes the current API; it does not certify that every backend yet provides the complete Basic-only game workflow required by the standard.


Basic functions

FunctionArgumentsDescription
ServernoneStarts the generic server on all configured service ports. The plugin accepts clients automatically and selects an interpreter from the destination port.
Stop_ServernoneStops the generic server and its service listeners.
ConnectType: stringConnects to the configured endpoint for HTTP, Echo, Chat, or Appeal.
DisconnectType: stringCloses the active connection of the specified type.
SendType: string, Message: stringSends a message through the active connection of the specified type.
ReceiveType: stringReceives data from the active connection of the specified type.
Get_IPDomain: stringResolves a domain name through the Network plugin.
RunScript: stringRuns a remote Appeal script through the configured Appeal connection.
DownloadRemote: string, Local: stringDownloads a complete file through the configured Appeal connection.

Advanced functions

FunctionArgumentsDescription
InitName: stringInitializes the module and loads its default plugin.
DebugValue: stringEnables or disables diagnostic logging for the module and active plugin.
Set_PathsResources: stringSets the root Appeal resources path used by the module.
Set_HTML_PathPath: stringSets the directory used for HTML server files.
ConfigureType: string, Host: string, Port: intStores the endpoint used by a connection type without opening a connection.

Globals

This module does not publish script-visible globals in its current module bridge. Plugin internals and C++ variables are not Appeal globals.

Reference source: module interpreter. Required arguments are not optional defaults. Advanced setup may be performed by Appeal configuration before a Basic script runs.

HTTPS support

Basic: Configure_TLS Certificate_File Private_Key_File returns 1/0 after validating PEM credentials. Is_Server_Running returns 1/0. Last_Error returns configuration/startup diagnostics. Advanced: Disable Type removes a configured endpoint before restarting. These commands return values without publishing globals.

Use Configure HTTPS Host Port and valid credentials before Server. TLS has a 1.2 minimum; HTTP remains available unless disabled. Failed HTTPS configuration does not open a plaintext substitute. Stop/restart for certificate rotation. Full setup, certificate, build, and validation guide.
